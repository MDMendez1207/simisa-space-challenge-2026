# Security Policy

## Supported versions

SIMISA is currently a hackathon prototype. Only the latest version on the `main` branch is maintained.

## Reporting a vulnerability

Please report vulnerabilities privately to the repository owner through their GitHub profile rather than opening a public issue. Include the affected component, reproduction steps, potential impact, and any suggested mitigation.

Do not include credentials, personal health information, or other sensitive data in reports, issues, commits, or screenshots.

## Current limitations

The prototype has no authentication, backend, medical-device integration, or production data storage. These omissions are part of its current scope, not security guarantees for a future system.
